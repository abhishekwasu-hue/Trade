# ADR 0004 — Internationalisation

Status: Accepted · 2026-10-12

- `flutter_localizations` + ARB (`app/lib/l10n/app_<lang>.arb`), English source. Adding a language
  = adding an ARB file; `supportedLocales` is generated, so no code change.
- Missing keys fall back to English (gen-l10n behaviour); `test/l10n/arb_completeness_test.dart`
  requires the launch set (`mr`, `hi`) to be complete and placeholder-consistent.
- Review flag per string (machine draft vs human-reviewed) will live in a translations table
  edited from the admin UI (M1), exported to ARB at build time.
- Numbers/dates use `intl` per locale with Indian grouping (`en` → `en_IN`); Marathi uses
  Devanagari digits, Hindi Latin digits (each locale's CLDR default).
- Server-side content (notification templates, agronomy text, AI output) is keyed by language
  in the DB from day one.
- Wave 2 (`te`, `kn`, `ta`, `ml`) needs fonts: Noto Sans per script downloaded on first use
  (keeps the APK small); planned in M1.
